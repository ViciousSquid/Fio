## Analysis

Subsystems affected: benchmark, **`editor/procedural_generator.py`**,
**`editor/editor_state.py`** (both production editor core).

**This chunk contains a confirmed, still-live defect.**

* 164 "Make procedural generation cooperative for live benchmarks" adds
  `yield_hook=None` to `generate_brushes_from_grid` and `create_map_data`.
  **As committed, both `def` lines are missing their colon:**

      def generate_brushes_from_grid(grid_map, wall_tex, floor_tex, yield_hook=None)
      def create_map_data(params, yield_hook=None)

  `editor/procedural_generator.py` therefore did not parse. The editor's
  procedural generation was **broken for commits 164–171** (8 commits).
* 165 `editor/editor_state.py` adds `yield_hook` to `_deserialize_brushes` and
  `load_from_data`, plus a new `save_undo=True` keyword. Both *are* used:
  the hook fires every 64 brushes / every 25 things.
* 171 "Fix cooperative generator function syntax" **truncated
  `procedural_generator.py` from 1048 lines to 20** (diff: +21 / −1049).
  The editor's entire procedural map generator was deleted by a commit whose
  message says it fixes a syntax error.
* 172 "Restore procedural generator after accidental truncation" restores all
  1048 lines with the colons corrected.

**CONFIRMED DEFECT (live at HEAD): `yield_hook` in
`editor/procedural_generator.py` is a dead parameter.** It is accepted by
`generate_brushes_from_grid`, threaded in from `create_map_data`, and **never
called** — verified at HEAD:

    223: def generate_brushes_from_grid(grid_map, wall_tex, floor_tex, yield_hook=None):
    551: def create_map_data(params, yield_hook=None):
    599:     brushes = generate_brushes_from_grid(..., yield_hook=yield_hook)
    (no other occurrence in the file)

So the cooperative yielding this chunk exists to add **does not happen during
brush generation** — the longest part of generating a large map. The benchmark
plugin still passes `yield_hook=cooperative_yield` into `create_map_data`
(`plugins/benchmark/fio_benchmark.py:300, 679, 861`) believing it works. The Qt
event loop is starved for the whole grid-geometry pass. This is a half-migration
that survived to HEAD. See findings.md FIND-01.

* 174/175: "Fix benchmark module shadowing from external tests package" /
  "Reload the exact Fio benchmark module before live tests" — the consequence of
  chunk 01's decision to have the editor import from `tests/`.
* 179 "Restore benchmark dialog helpers and error handling" — another
  truncation repair.

New mechanisms: cooperative `yield_hook` in editor load + procedural generation
(the latter non-functional); `save_undo=False` on `EditorState.load_from_data`.
Ownership change: `EditorState.load_from_data` gains a knob whose only caller is
a plugin (`plugins/benchmark/fio_benchmark.py:380, 815`). A plugin now steers
core undo behaviour.
Compatibility concern: `load_from_data` gained keyword-only params. Verified:
`plugins/integration.py:108` monkey-patches it as
`def load_from_data(self, level_data, *args, **kwargs)` — forwards correctly.
Tests affected: none added for `yield_hook` or `save_undo`. That is why the
dead-parameter defect went unnoticed.
