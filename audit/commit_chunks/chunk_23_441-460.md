## Analysis

Subsystems affected: **physics correctness, Prop friction, property editor**.

This chunk is almost entirely bug-fixing the physics move of chunk 22, with a
test added for each — the healthiest stretch of the range.

* 444 "Fix missing Prop import in property editor" — the panel referenced
  `Prop` without importing it; an editor crash.
* **445–454: floor contact, fixed five times, each with a regression test.**
  "Fix dynamic prop floor contact while pushing" (445) + test (446), aligned to
  the model origin (447); "Fix prop floor contact while sliding" (448) + test
  (449); "Use downward raycast for prop floor contact" (450); **"Fix dropped
  props crossing floor during raycast" (451)** + test (452) — tunnelling, the
  classic failure of a position-only floor test at speed; "Keep pushed props
  grounded across floor seams" (453) + test (454) — a body straddling two
  brushes losing support.
  Five distinct floor bugs is what replacing a `raycast_down`-and-snap model
  with a real swept contact test costs. All five have tests.
* **455 "Use real OBJ bounds for prop collision"** — completes 414's automatic
  bounds by reading the mesh instead of guessing.
* **456 "Make prop friction work as ground friction"** + test (457). Before
  this, `friction` was an authored property the baseline sim **never read**
  (see baseline.md §6). Now it is Coulomb friction applied only while grounded:
  `a = mu * g`, clamped so it cannot reverse the body. Verified: with the
  default `mu=0.55` and `g=900`, a body entering at 100 u/s stops after
  `v^2/2a = 10.10` units. The test that shipped asserted `< 10.0` — below the
  analytic answer, so it could never pass (see fixes.md).
* 458/459 move friction into the Physics settings and give it a control;
  460–462 add a Model collision-shape selector.

New mechanisms: ground friction; mesh-derived collision bounds; swept floor
contact.
Ownership change: `friction` moves from an unused authored key to a live
simulation parameter. **Any 2.4.2 map with a non-default `friction` now behaves
differently** — previously the value was inert. Recorded in compatibility.md.
Tests affected: 446, 449, 452, 454, 457 — five regression tests, all of which
pass once the suite is collectable.
