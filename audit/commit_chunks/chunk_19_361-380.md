## Analysis

Subsystems affected: **renderer — GPU instancing and the shared light UBO**.

**Phase D: the second architectural transformation, and the least clean.**

* **364 "Add GPU-instanced model rendering"** — models move from per-object
  draw calls to instanced draws.
* **365–370: the shared GL3.3 light UBO.** What existed before → what replaced
  it: at baseline, lights were uploaded per shader program via
  `_upload_lights_once(shader_name, lights)`. Now a single std140 uniform block
  is uploaded once per frame and bound by every lit shader, including terrain
  (368) and water. 369 resets the UBO cache each frame; 379 packs it with NumPy
  into a structured array.

**The migration was not clean.** Eleven repair commits follow:

* 366 "Fix light UBO shader regex", 397 "Fix light shader rewrite regex",
  398 "Fix light shader replacement groups" — the shader sources are
  **rewritten by regular expression at runtime** to inject the UBO block. That
  is the mechanism, and three separate commits were needed to get the regex
  right. Recorded in architecture.md as the single most fragile thing in the
  renderer.
* 372–375: "Fix syntax error in GPU instanced shader source patch", "Fix
  instanced shader source transformation", **"Fix GLSL newline escapes in
  instanced shader generation"**, "Correct newline escaping in instanced GLSL
  source". The generated GLSL was emitted with **literal `\n` escapes instead
  of newlines** — twice. This is the same defect class that shipped in
  `tests/renderer/test_light_budget.py` at commit 396 and made the whole test
  module unparseable (see testing.md).
* 385/386/387: "Fix renderer_core syntax error", "Fix second renderer_core
  syntax corruption", "Fix renderer_core indentation error" — three commits to
  make `renderer_core.py` parse again.
* 390–395: six commits on the UBO's std140 layout ("Fix dynamic-light UBO
  layout for play mode", "Fix fixed-size light UBO packing", "Fix light UBO
  structured-array reset", "Fix light UBO field indexing", "Restore shared
  light UBO struct layout", "Restore light UBO struct packing").
* **378 "Restore dedicated shadow sampler bindings after UBO refactor"** — the
  UBO refactor had broken shadow sampler binding. A real regression, caught and
  fixed in-phase.
* 376/377 add GL draw-state diagnostics for textured-brush failures, then move
  them off the hot path.

* 380–384: the light list becomes authoritative in the render state
  ("Publish authoritative light list in render state" appears **twice**, 380
  and 384 — a duplicated commit). 383 "Avoid full Thing scans when collecting
  lights" is the performance point: lights are collected by the logic thread
  once, not rescanned per frame by the renderer. `qt_game_view` gains
  `_render_config["all_lights"]`, with a documented editor fallback when no
  render state exists.

* 371/396 update the light-budget tests. **396 is the commit that broke them**
  — see testing.md. Consequence: this entire 35-commit transformation, with its
  eleven repair commits, had **no working test coverage from 396 onward**,
  because its own test module stopped parsing and pytest aborts the whole run
  on a collection error.

New mechanisms: GPU instancing; shared std140 light UBO; runtime shader-source
rewriting by regex; authoritative render-state light list.
Removed mechanisms: per-shader light upload (`_upload_lights_once`).
Migration completeness: functionally complete at HEAD (the light-budget suite
passes once repaired — 26 tests), but reached through eleven repairs with the
test module dead for most of it.
Architectural concern: **runtime regex rewriting of shader source** is the
mechanism three commits failed to get right. It is unavoidable-ish given the
ARM/desktop variant split, but it is untested at the string level.
