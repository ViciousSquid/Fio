## Analysis

Subsystems affected: **Prop, physics, property editor**.

**Phase E: Prop becomes a physical primitive.**

* 401–407: the merged-then-unmerged physics/collision control (see chunk 20).
  Settles on **independent** `physics_enabled` and `no_collision`.
* **409/410 "Keep dynamic Props out of static collision grid" / "Tag
  physics-enabled Prop collision bodies as dynamic"** — the ownership change.
  At baseline, model collision was *baked into brushes* and everything lived in
  one `SpatialGrid`. Now a physics-enabled Prop's brush is tagged
  `_physics_body` / `_physics_entity` and kept out of the static grid, because
  a moving body must not be a static collider.
* 411 "Add pushable physics for Props", 413 tests it, 415 "Keep pushed Props
  moving after landing".
* **412 "Let PropSession handle dynamic Prop collision"** — a first attempt
  that puts the simulation in `PropSession`. **Superseded at 422–425**, which
  move it into `engine/physics.py` and reduce `PropSession` to interaction
  only. Two owners for dynamic-body simulation existed between 412 and 425.
* 414 "Treat zero Prop collision size as automatic bounds" — `collision_size`
  `[0,0,0]` (the authored default) now means "derive from the mesh", which is
  what makes the default usable. Later refined by 455 ("Use real OBJ bounds").
* 416–421: `mass`, `solid` and an explicit `collision_shape` control
  (`auto` / `aabb`, later `mesh`). 421 classifies collision shape as a primary
  property so it appears in the panel.

New mechanisms: dynamic bodies, `_physics_body` brush tagging, `collision_shape`,
automatic bounds from mesh.
Changed data format: Props gain `collision_shape`; `collision_size` `[0,0,0]`
changes meaning from "no size" to "derive automatically". **This is a
compatibility-relevant semantic change to an existing key** — a 2.4.2 map with
the default `[0,0,0]` now gets mesh-derived collision where before it got none.
Recorded in compatibility.md. It is almost certainly the *intended* improvement,
but it is a behaviour change to existing saved data, not just to new content.
Tests affected: 403, 407, 413, 420 add Prop physics tests.
